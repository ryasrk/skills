# Tools

Utility functions and generators for constraint-driven ML research.

## Directories

### utils
Common utilities (data loading, metric calculation, constraint enforcement)

### generators
Code and report generators for experiments

### parsers
Configuration parsers and result file readers

## Usage

```python
from Tools.utils.constraint_enforcer import enforce_cgroup_limits
from Tools.parsers.metrics_json import load_results_from_json
```
